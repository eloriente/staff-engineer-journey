  Nowadays, automated testing is a well-established engineering practice. The real challenge is no longer writing tests, but ensuring they remain valuable, maintainable and trustworthy as the system evolves.

## Reflection

Although the course presents four rules for sustainable code, I believe that automated testing has become a baseline expectation in modern software development.

What really differentiates a sustainable codebase is not simply having tests, but having tests that are easy to understand, maintain and trust over time.

Poorly designed tests can become as costly to maintain as poorly designed production code, reducing confidence instead of increasing it.

## Engineering Decision

When writing automated tests, I will prioritise clarity and maintainability over coverage metrics.

A smaller set of reliable and understandable tests provides more long-term value than a large suite of fragile tests.
